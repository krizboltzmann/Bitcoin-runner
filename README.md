A browser-based endless runner game inspired by the Chrome offline dinosaur game — rebuilt with a crypto twist.

The goal is simple: survive as long as possible, collect Bitcoin, and avoid rugs.

---

## About

This is a lightweight, frontend-only game where:
- A human-like runner moves automatically
- You jump over obstacles and collect BTC
- Hitting rugs or bombs costs you coins and lives
- Difficulty ramps up gradually over time

The game is designed to start easy, feel fair, and get harder the longer you survive.

---

## Controls

- **Space** — Start game / Jump  
- **Escape (ESC)** — Pause / Resume  
- **Click / Tap** — Jump (mobile-friendly)

You start with **3 lives**.  
Game ends when all lives are lost.

---

## Features

- Endless runner gameplay
- Progressive difficulty curve
- Bitcoin collectibles
- Rug / bomb obstacles
- Lives + score system
- Pause & resume support
- Sound effects with mute toggle
- Desktop & mobile compatible
